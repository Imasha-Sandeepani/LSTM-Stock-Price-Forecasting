# LSTM-Based Stock Price Forecasting

An end-to-end deep learning project for forecasting stock prices
of Amazon (AMZN), eBay (EBAY), and Etsy (ETSY).

## Project Overview

This project applies Long Short-Term Memory (LSTM) neural networks
to historical stock market data to generate short-term stock price
forecasts.

The project includes:

- Historical stock data extraction using Yahoo Finance
- Exploratory Data Analysis (EDA)
- Data preprocessing and scaling
- Time-series sequence preparation
- LSTM model development
- Hyperparameter tuning
- Model evaluation
- Future stock price forecasting
- Equity market analysis

## Technologies

Python | Pandas | NumPy | Keras | Scikit-learn | 
Yahoo Finance | Matplotlib | Plotly

## Stocks Analyzed

- Amazon (AMZN)
- eBay (EBAY)
- Etsy (ETSY)
